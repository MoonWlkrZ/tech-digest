一句话判断

EP227 是一期复习型周末刊，主干是围绕 TypeSafe AI 决策模型 Jev 的场景清单——「LLM 负责生成，小模型负责决策」，给出 9 个可以下沉到小模型的位置；另外两节复习信息密度更高：MCP 与 function calling 的差异、Claude Code 上下文窗口的 9 个来源。厂商数字没有评测支撑，但三块拼起来是给 agent 工程用的一张低成本对照表。3/5 星：轻量，值得留档。

1. 文章主张了什么

  • Top 9 Places to Use Jev（主文）：Jev 是 TypeSafe AI 的「System One Model」（对照思考快速的系统一），主张比前沿 LLM 快 100 倍、便宜 100 倍，因此可以用在以往因大模型太慢太贵而被跳过的场景——① 模型路由：把 prompt 路由给合适的 LLM；② 护栏：先检测 prompt 安全风险再交给 LLM；③ 工具调用门控：把 agent 的工具调用分类到对应权限档；④ 收件箱分流：邮件分类（垃圾/紧急/归档）；⑤ 重排序：给检索段落按相关性打分；⑥ LLM 评测：给模型输出打分；⑦ 批量标注：大表逐行打标（map-reduce 式）；⑧ 实时决策：循环内需要快速判断的场景（如交易）；⑨ 置信度闸门：按置信度分类并采取相应动作。结论句：把生成交给 LLM，把围绕它的决策交给 Jev。
  • LLM / RAG / AI Agent / Agentic AI：词条式定义复习——LLM 按 token 逐字预测；RAG 先检索再注入，回答有出处但不保证正确；AI agent 有目标与任务状态，能规划、调工具、观察结果并循环直到达成；Agentic AI 是把一个或多个 agent 用编排层组织起来共享目标，agent 之间读写共享任务状态。
  • MCP vs function calling：两者机制相同——runtime 把 prompt 发给 LLM，LLM 决定并发出 tool call，runtime 执行后把结果回传，LLM 产出最终输出；差别只在函数实现在哪里、由谁执行：本地 function calling 的函数在用户机器上实现并执行；MCP 的函数可以在远端服务器上，runtime 按协议调用、远端执行、结果回传，从而接入大量公开托管的工具。
  • If Claude Code is a burger...：把 Claude Code 每次模型调用前组装的上下文窗口拆成 9 层来源：系统提示；环境信息（git 状态、分支、日期，经 getSystemContext()）；CLAUDE.md 四级指令层级（managed → user → project → local，纯文本可读可改可版本化）；自动记忆（异步预取，最多浮出 5 个相关文件）；路径限定的惰性规则（读到文件时才加载）；工具元数据（skill 描述、MCP 工具名、延迟加载的工具定义）；对话历史；工具结果（文件读取、命令输出、子代理摘要）；会话过长后的压缩摘要。

2. 我的解读

  • 「生成 vs 决策」的拆分本身不新（小型分类/打分模型做路由、护栏、重排序是近年 agent 栈的常见做法），但这篇把它收拢成一句可以直接复述的心智模型：围绕 LLM 的每一次「是/否、哪一类、多相关」都可以下沉到便宜快模型，大模型只做不可替代的生成。
  • 主文要看清性质：它没有给评测、延迟/成本口径或失败案例，「100x」是厂商主张，且文中没有标注 sponsored（顶部 webinar 标了）。把它当场景清单读——9 个位置可以逐条对照自己的 agent 栈，数字不要当事实。
  • MCP vs function calling 一节把常见混淆点讲清了：两者不是竞争协议，差别在函数部署位置（本地 vs 远端）与随之而来的工具生态。做工具接入评审时是一个干净的解释框架。
  • Claude Code 上下文拆解是本期信息密度最高的一节：它解释了 CLAUDE.md 的四级层级、自动记忆的预取、路径限定规则的惰性加载与压缩摘要如何在同一次调用里叠加。配合文末「多不等于好——把 200 个文件塞给 agent 反而更难」与 task-specific context packet 清单（目标、约束、过往决策、编码约定、好例子、已知边界情况、完成定义、只带真正需要的文件），是可以直接照做的实践建议。

3. 对工程实践的意义

  • 上下文工程：与其扩窗口，不如改选择。任务级 context packet 的清单可以直接落到团队的 CLAUDE.md / AGENTS.md 与任务模板里。
  • 工具接入：用「本地 vs 远端」框架向团队解释 MCP 与 function calling 的关系，决定哪些工具自建、哪些走远端托管。
